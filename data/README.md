# Data

This project uses the public **Credit Card Fraud Detection** dataset from the ULB Machine Learning Group:
284,807 card transactions made by European cardholders over two days in September 2013, of which 492 are fraud.

1. Download `creditcard.csv` from Kaggle: https://www.kaggle.com/datasets/mlg-ulb/creditcardfraud
2. Place it in this folder as `data/creditcard.csv`.

The file is about 150 MB and is not stored in this repository (GitHub limits files to 100 MB).
The dataset is published under the Open Database License.

Citation: Andrea Dal Pozzolo, Olivier Caelen, Reid A. Johnson and Gianluca Bontempi,
"Calibrating Probability with Undersampling for Unbalanced Classification", IEEE Symposium Series on Computational Intelligence, 2015.
